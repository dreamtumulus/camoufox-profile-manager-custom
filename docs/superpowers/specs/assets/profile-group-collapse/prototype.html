标注说明

  1. 1显示方式切换：「列表」是现在的平铺分页表格，「按分组」是新的折叠视图。选择记在本机浏览器里。
  2. 2全部展开 / 全部折叠，只在「按分组」下出现。
  3. 3分组标题行：点整行展开或折叠。显示本组数量、运行中数量、封禁和代理异常数量、最近使用时间。有运行中的组左侧带橙色细线。
  4. 4分组复选框：一次选中本组全部配置，折叠状态下也生效；只选了一部分时显示半选。
  5. 5组内的行和现在完全一样，只是去掉了重复的「分组」列，表格变窄，右侧「运行」按钮不再被挤出屏幕。
  6. 6底部改为「分组数 · 配置数」。按分组显示时不分页，折叠的组不渲染行；单组超过 50 行时组内「显示更多」。
  7. 7搜索或筛选时：没有匹配的组隐藏，有匹配的组自动展开，数量显示为「匹配 3 / 9」。清空搜索后恢复原来的折叠状态。
  8. 8「运行本组」（可选，建议二期）：复用现有的批量启动对话框，一次启动整组。
